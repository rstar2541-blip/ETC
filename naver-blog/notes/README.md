# 오너 메모

소유했던 차의 실제 경험을 적어 두면, 그 차 글을 쓸 때 이 메모를 중심으로 씁니다.
메모가 없으면 구체적인 사건은 지어내지 않고 `[확인: 실제 경험으로 채워 주세요]`로 비워 둡니다.

파일 이름은 `config/models.json`의 id를 씁니다.

| 차 | 파일 |
|---|---|
| E82 135i | `e82-135i.md` |
| E93 335i 컨버터블 | `e93-335i.md` |
| F87 M2 컴페티션 | `f87-m2c.md` |
| F80 M3 | `f80-m3.md` |
| F82 M4 | `f82-m4.md` |
| F83 M4 컨버터블 | `f83-m4-cabrio.md` |
| G80 M3 | `g80-m3.md` |

관심 모델도 시승 경험이 있으면 같은 방식(예: `g87-m2.md`)으로 적으면 됩니다.

## 양식 (짧게 적어도 됩니다)

```
보유 기간: 2019.03 ~ 2021.08
연식·주행거리: 2018년식, 인수 3만 km → 매각 7만 km
용도: 출퇴근 + 주말 와인딩
튜닝: 배기, 휠·타이어(PS4S)
정비·고장: 6만 km에 워터펌프 교체, 비용 ○○만 원
좋았던 점: ...
아쉬웠던 점: ...
기억나는 에피소드: ...
판 이유: ...
```
