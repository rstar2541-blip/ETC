# 브릿지 스쿼드

다리 위에서 좀비 떼를 막아내는 스쿼드 러너 슈팅 게임. 브라우저에서 `index.html` 하나만 열면 바로 플레이할 수 있어요 (빌드나 설치 필요 없음, 모바일 터치 지원).

## 플레이 방법

- **이동**: 화면을 좌우로 드래그 (PC는 ←/→ 또는 A/D). 사격은 자동.
- **숫자 게이트**: 지나가면 대원 수가 `+N`, `-N`, `×N` 만큼 바뀌어요. 게이트를 쏘면 숫자가 올라가니 `-8` 게이트도 쏴서 플러스로 만들 수 있어요. 대원이 많을수록 숫자를 올리는 데 더 많은 총알이 들어요.
- **캡슐(받침대)**: HP가 0이 될 때까지 쏘면 보상을 얻어요.
  - 주황 캡슐: 무기 업그레이드 (권총 → 기관단총 → 돌격소총 → 미니건 → 플라즈마 → 레일건)
  - 보라 캡슐: 전투 메카 합류 (근처 좀비에게 자동으로 범위 포격)
  - 초록 캡슐: 대원 추가
- **좀비**: 스쿼드에 닿으면 대원을 잃어요. 스테이지 2부터 빠른 좀비, 4부터 덩치 큰 좀비가 나와요.
- **보스**: 스테이지 끝에서 거대 좀비가 다가와 내려찍기로 대원을 쓸어버려요. 쓰러뜨리면 다음 스테이지로.

스테이지가 오를수록 좀비가 많아지고 단단해집니다. 최고 기록은 브라우저에 저장돼요.

## 실행

```bash
# 그냥 파일을 열어도 되고, 로컬 서버로 띄워도 됩니다
python3 -m http.server -d bridge-squad 8000
# http://localhost:8000
```
