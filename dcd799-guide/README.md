# DCD799 해머 드릴 드라이버 — 3D 사용 설명

DCD799P1T 사용 설명서의 **그림 A–G(2–3쪽)** 와 **한국어 설명(10–15쪽)** 을 16단계 3D 애니메이션으로 옮긴 웹 페이지입니다.
공구 형태와 비율은 판매 페이지의 제품 사진(측면·정면·상단)에서 실루엣을 측정해 만들었습니다.

## 실행

`index.html`을 브라우저(Chrome, Edge, Safari, Firefox)로 엽니다.
3D 엔진(three.js 0.170.0)을 jsDelivr CDN에서 불러오므로 인터넷 연결이 필요합니다.

| 조작 | 동작 |
| --- | --- |
| 재생 / 일시정지 버튼, `Space` | 애니메이션 재생·정지 |
| ⏮ ⏭, `←` `→` | 이전·다음 단계 |
| 진행 막대 | 단계 안에서 원하는 시점으로 이동 |
| 오른쪽 설명 문장 클릭 | 그 문장이 시작되는 시점으로 이동 |
| 드래그 / 휠 / 두 손가락 | 모델 회전 / 확대 / 이동 (‘시점 되돌리기’로 자동 카메라 복귀) |
| 연속 재생 | 켜 두면 마지막 단계까지 이어서 재생 |

## 단계 구성

| # | 단계 | 설명서 |
| --- | --- | --- |
| 1 | 구성품 살펴보기 (① ~ ⑫ 번호 표시) | 그림 A |
| 2 | 작업 전 안전 확인 | 안전 지침 |
| 3 | 배터리 팩 장착 | 그림 B |
| 4 | 배터리 팩 분리 | 그림 B |
| 5 | 연료 게이지 확인 | 그림 B |
| 6 | 벨트 후크·비트 클립 장착 | 그림 G |
| 7 | 키리스 척에 비트 설치 | 그림 C |
| 8 | 속도 선택 (1단 0–450 / 2단 0–1,650 rpm) | 그림 A, E |
| 9 | 모드 선택 (드릴 · 1–15 · 해머) | 그림 A, D |
| 10 | 올바른 손 위치 | 그림 F |
| 11 | 트리거와 회전 방향 (정회전·역회전·잠금) | 그림 A |
| 12 | 작업등 (20초 후 자동 꺼짐) | 그림 A |
| 13 | 스크류 구동 (클러치 작동) | 작업 수행 |
| 14 | 드릴링 | 작업 수행 |
| 15 | 해머드릴링 | DCD799 |
| 16 | 청소와 유지 보수 | 유지 보수 |

화면 왼쪽 위에는 단계에 따라 모드, 속도, 회전 방향, 트리거 압력에 따른 rpm/bpm이 표시됩니다(설명서 기술 데이터 기준).

## 3D 모델 파일

`dcd799.glb` — 같은 모델을 glTF 바이너리로 내보낸 파일입니다(단위: m, 벨트 후크 장착 상태).
움직이는 부품은 이름이 붙은 노드로 나뉘어 있어 Blender 등에서 따로 애니메이션할 수 있습니다:
`batteryPack`, `releaseButton`, `modeCollar`, `spindle`, `chuckSleeve`, `speedSelector`, `trigger`, `forwardReverse`, `beltHook`, `screw13`.
